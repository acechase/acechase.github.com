Doomsday Tunnels 3D · Privacy

What the app knows about you

Almost nothing. The game has no accounts, shows no ads, uses no analytics service and does not track you across other apps or websites. Nothing it sends says who you are, apart from a name you choose to type when you post a score.

What the game counts

The game keeps daily totals so its maker can tell whether anyone is playing. You can switch this off: Count my plays in the settings panel (the gear button). With it off, the game still asks the server for a start time, which it needs if you later post a score, but nothing is added to the totals.

The demo that plays by itself on the title screen is not a run. It sends nothing and saves nothing.

What is sent, and when

When you start a run

The app sends
That a run has started. Whether it is the first run on this phone today, and the first ever. Whether you are playing by touch, and whether tilt steering is on.
The server keeps
One more on that day's totals: runs, players, new players, touch runs and tilt runs. It replies with a start time for this run, which the app hands back if you post a score.

When a run ends

The app sends
The sector you reached, how many sectors you cleared, and how many seconds the run lasted.
The server keeps
That day's totals again: runs finished, seconds played and sectors cleared, plus a count of how many runs ended in each sector.

When you choose to post a score

The app sends
The name you typed, your score, the sector you reached, and your time for each sector you cleared in that run.
The server keeps
That name with its best score, the sector and the date, and that name's fastest time for each sector. This is the public scoreboard, which anyone playing the app can see.

When you choose to post a daily sector time

The app sends
The name you typed, the day, and your time through that day's sector.
The server keeps
That name's fastest time for the day. This is the public daily board.

Looking at a scoreboard sends nothing about you. Only the game's maker can see the daily totals. Days are counted in UTC. The app's scoreboard is kept apart from the web game's.

How players are counted without knowing who they are

The app remembers the date you last played. When you start a run it answers one question for the server: is this the first run on this phone today, yes or no? The server adds up the yeses. It never receives anything that could tell two phones apart.

What is never stored

  • Your IP address. The server uses it for about a minute to slow down spam, as described under other companies involved, and never writes it down.
  • Your phone's model, its operating system or its screen.
  • Your location.
  • Any ID for you or your phone, including Apple's advertising identifier.
  • A record of individual runs. Only the daily totals above are kept.

What stays on your phone

The app saves a few things on your phone. They are never sent anywhere, apart from the name when you post a score or a time.

  • Your settings: controls, the feel sliders, sound, music, haptics, the ghost and play counting.
  • Your best score, your best time for each sector, and the ghost of your best run through each sector.
  • Your best time through today's daily sector.
  • The name you last posted, so it is filled in next time.
  • The date you last played.
  • Whether you have bought the supporter purchase.

Deleting the app removes all of it.

The supporter purchase

The game is free. After a game it may ask you to support its development with a one-time purchase, which stops that request from appearing again. The purchase is made through Apple. The game's maker never sees your name, your Apple Account or your payment details; the app only learns from Apple whether the purchase has been made, so it can stop asking.

Other companies involved

  • Apple delivers the app through the App Store and handles the supporter purchase, under Apple's privacy policy.
  • Cloudflare runs the scoreboard server. To stop one connection from flooding it, the server uses your IP address as a counter inside Cloudflare that lasts about a minute. It is never written to the game's database.
  • GitHub hosts this page. GitHub logs the IP address of visitors to every site it hosts, for security. The app itself never contacts GitHub, except when you open this page, the support page or the ship sheet from it.

The server's code is public. You can read exactly what it stores.

Removing a name

A posted name is not an account and has no password. The game's maker can remove any entry from the boards. To ask for a name to be taken down, open an issue on GitHub.

Children

The game collects nothing from anyone beyond what this page describes, whatever their age. A child can play without posting a score, and nothing about them leaves the phone except the anonymous daily counts, which can be switched off.
